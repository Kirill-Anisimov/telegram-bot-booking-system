# telegram-bot-booking-system
Телеграм бот для бронирования занятий в школе музыки.

## Структура проекта

```text
telegram-bot-booking-system/
│
├── bot.py                # Точка входа
├── config.py             # Настройки (токен, время работы)
├── database.py           # Подключение к SQLite/Postgres
├── models.py             # SQLAlchemy модели
├── handlers/             # Отдельные функии используемые ботом
├── keyboards/            # inline и reply клавиатуры
└── utils/                # вспомогательные функции
```
